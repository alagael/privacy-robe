# Security policy

## Supported versions

The latest tagged 0.1.x release receives fixes. There is no guarantee of an emergency response time.

## Private disclosure

Email **support@alagael.xyz** with the affected version, minimal reproduction, impact, and proposed mitigation. Never include real seed phrases, private keys, wallet backups, or funds.

These components are public beta and **not independently audited**. Tests are not an audit or a guarantee against loss. Ethereum transactions and contract settings are public; local cryptographic operations do not make blockchain activity anonymous.

No contributor needs your private key or seed phrase to investigate a bug. Use disposable fixtures and accounts only.
